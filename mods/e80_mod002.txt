# =====================================================================
# mod002 -- on-device screen capture ("grab") over TCP / 6668
# =====================================================================
# Add a fast, tear-free full-screen capture to the running E80: a host sends one
# GRAB command to the TCP Diagnostics port (6668); the device takes a raw atomic
# snapshot (GDC2 register block + CLUTs + each enabled layer's raw buffer) into a
# heap scratch and streams it back over the same connection. The host composites
# and writes the PNG -- nothing is converted on the device. Also stamps the app's
# reported version to 5.72.
# =====================================================================
