# =====================================================================
# mod003 -- per-track-point datetime (+ corrected depth), DB-toggled
# =====================================================================
# E80 track points natively carry position + depth(cm) + temp(K), but no time.
# This mod makes the on-device recorder stamp each committed point with a real
# wall-clock value, so standalone-recorded tracks (navMate is NOT connected while
# the E80 records) are date-stamped.
#
# Toggle -- a DB value gates the behavior, so it can be turned off without a reflash:
#   fid 0x05ff0001 (BOOL8, ENC 0x0054) -- a novel item minted over the stock DB
#   protocol (see abstracts/DB_FIDS + abstracts/DATABASE; persists across reboot on
#   E80-2). Read each point via the stub's read_item helper:
#     value 0 OR ABSENT -> write timed tracks   (default)
#     value nonzero     -> write stock non-timed tracks
#   read_item returns 0 for both "explicitly 0" and "item not present", so a unit
#   that never had the fid minted gets timed tracks by default. navMate carries a
#   purpose-built UI that sets/clears this one fid (a small tool mints it, another
#   flips it); the mod itself only READS it.
#
# Mechanism -- ride the existing storage/serve/round-trip machinery, length-preserving:
#   [A] retarget the `bl addPoint` in all three track emit sites to `bl mod003_stub`.
#   [B] mod003_stub -- the datetime/depth injector in the InterNiche dev-CLI reservoir
#       (run 06), with the toggle read at its head. It reads fid 0x05ff0001; if set it
#       branches to the epilogue and tail-calls addPoint with the point UNTOUCHED (stock
#       track). Else it reads the day/time data items, packs datetime =
#       (date & 0xffff)*86400 + time/10000 (unix sec) into the point's DEPTH field and
#       real depth (0.1 ft) into the junk TEMP field, then tail-calls addPoint.
#   [D] bump the SysInfo build-stamp self-check + fallback to 573 (v5.73 DOB).
#
# A datetime in the DEPTH slot is ~1.78e9 -- an impossible depth -- so a consumer
# identifies a timed track from the point values themselves; no track-type flag is set.
#
# BASE: apply onto e80_base + mod001 + mod002, where run 06 holds stock InterNiche code;
# the SHA-256 guard aborts cleanly otherwise.
# =====================================================================
