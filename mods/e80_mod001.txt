# mod001 -- diagnostics debug primitive (peek / poke / call) over UDP 6667
# =====================================================================
# Add a remote read-memory / write-memory / call-function primitive to the running
# E80, so runtime unknowns can be settled empirically against real bytes on the
# device. This is a debug primitive, not a feature. Length-preserving: the bytes
# overwritten are positively-known dead code, given up on purpose.
# =====================================================================
